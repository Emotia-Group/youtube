# Biblioteca de música

Coloca aquí pistas libres de derechos (.mp3/.wav/.m4a/.flac/.ogg) para usar
`providers.music.name: library` en config.yaml.

Consejo: incluye el mood en el nombre del archivo (ej. `cinematic-tension.mp3`,
`upbeat-corporate.mp3`) — el sistema prioriza las pistas cuyo nombre contiene
el mood definido en el concepto del video.

Fuentes recomendadas: YouTube Audio Library, Pixabay Music, Free Music Archive.
