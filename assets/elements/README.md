# Banco de elementos de archivo (insertos documentales)

Aquí vive TU material de superposición: cuando la narración menciona a un
personaje, lugar, entidad, etc., el documentalista de archivo busca primero
en estas carpetas — **tu material siempre tiene prioridad sobre internet**.

## Cómo usarlo

1. Coloca imágenes (`.jpg`, `.png`, `.webp`) en la carpeta de su categoría:
   - `personajes/` — p. ej. `elon-musk.jpg`, `mansa musa.png`
   - `lugares/` — p. ej. `el-cairo.jpg`, `desierto del sahara.webp`
   - `entidades/` — p. ej. `unesco.png`, `forbes.jpg`
   - `mapas/` — p. ej. `imperio de mali.png`
   - `stickers/` — adornos de estilo libre para canales que lo admitan
2. El **nombre del archivo** es la clave de búsqueda: sin importar tildes,
   mayúsculas o guiones (`El-Cairo.jpg` encaja con la mención «El Cairo»).
3. Usa SOLO material de uso libre (CC0/dominio público) o propio: packs
   gratuitos de Pixabay, Pexels, Mixkit, Openverse…

Si aquí no hay coincidencia, el programa busca la foto del artículo de
Wikipedia (solo licencias libres verificadas) y añade el crédito
automáticamente a la descripción del video. Las cifras y fechas no necesitan
archivos: se generan en tu equipo, gratis.
